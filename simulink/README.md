# Simulink model

Place the manually organised `.slx` model here. Suggested filename: `heater_thermostat_baseline.slx`.

Before committing:
- Confirm it opens without unresolved variables.
- Record MATLAB/Simulink version and solver settings.
- Ensure parameters and stop time are clear.
- Avoid committing temporary files, `slprj/`, autosaves, and caches.
