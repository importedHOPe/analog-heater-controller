# Safety

This repository documents an educational simulation and controller concept, not a certified safety system. Immersion heaters operate at hazardous mains voltage near water. Never leave a prototype unattended, use it as the only over-temperature/dry-run protection, or bypass built-in protections. Any physical mains build requires qualified electrical review, proper isolation and enclosure, overcurrent protection, correctly rated components, and independent thermal cut-outs. Do not work on live mains wiring.
